# distribution-channel-picker

分发渠道选择器 —— "Building is the easy part, distribution is the moat"。

## 方法
用五维打分（受众贴近度 / 执行可行性 / 反馈速度 / 复利潜力 / 成本可持续）从 7 个有效渠道里选出 2 个主渠道，连续跑六周 sprint，期间不换渠道、不加第三个。

## 包含内容
- `SKILL.md`：输入清单、七渠道、五维打分规则、六周 sprint 模板、标准输出格式
- `references/channels.md`：七渠道详解 + 中国渠道映射（V2EX / 即刻 / 小红书 / 视频号 / B站 / 知乎 / 公众号等）
- `references/scorecard.md`：打分标准、空白打分表与完整示例
- `references/sprint-plan.md`：六周执行计划模板

## 用法
把本仓库作为 AI 助手的知识库，告诉它你的项目（ICP、解决的问题、时间/技能/预算），让它输出渠道打分表、Top 2 建议与六周计划。
